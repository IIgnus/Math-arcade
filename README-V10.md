# STEM Quest v10

This package upgrades the working v9 project with mobile layout improvements and optional developer testing tools.

## Upload
Replace `app.js` and `styles.css`, then add `js/dev-tools.js`.

Do not replace your question content or Firestore rules for this update.

## Enable developer tools
Press **Ctrl + Shift + D**. The setting is stored only in that browser. Press the shortcut again to hide the tools.
